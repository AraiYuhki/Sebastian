ローカル完結型 CI エンジン

手元のマシンで、
サーバーを立てずに回すCI。

なぜ sebastian-ci か

重いCIサーバーは、もう要らない。

従来のCIが抱える3つの痛みを、設計そのもので解消します。

01 / サーバーレス

常駐プロセスゼロ

叩いたときだけ動きます。管理画面が必要なときは serve でその場に立て、閉じれば消えます。

02 / クリーン

環境を汚さない

各ジョブは --rm の使い捨てコンテナ内で実行。ホストにツールを入れる必要はありません。

03 / Git ネイティブ

無駄を回さない

コミットハッシュで実行済みを自動スキップ。変更のあった範囲だけを賢く回します。

機能

実運用に必要なものは、ひととおり。

.sebastian-ci.yaml ひとつで、依存関係・並列・最適化・通知までを宣言的に定義します。

実行制御

パイプラインを思いどおりに

  • DAG 並列実行：needs で依存を解決し、独立ジョブは同時実行
  • ステージで大きな実行順序を制御
  • マトリックス：matrix で複数条件を並行ビルド
  • timeout / retry / continueOnError による失敗制御
  • --max-parallel で同時実行数を制限
最適化

速く、無駄なく

  • 変更検知：changes に一致しなければジョブをスキップ
  • キャッシュ：cache で ~/.nuget 等をコミット横断で永続化
  • 実行済みコミットの自動スキップ（--rebuild で強制）
  • --validate で実行せず構成だけを検証
  • --job で狙ったジョブと依存だけを実行
可観測性

状況が、すぐ分かる

  • 標準出力・標準エラーをリアルタイム表示＋ログ保存
  • 実行履歴・ログ・成果物を .sebastian-ci/ に永続化
  • メモリ・ディスクのリソース監視と警告
  • Slack / ChatWork 通知（送信タイミングを on で指定）
  • 中断（Ctrl+C / kill）時もコンテナを確実に後片付け
受け渡し

成果物と秘密情報

  • 成果物：artifacts で生成物を退避・保存
  • 動的な環境変数：$NAME でホストの値を注入
  • 秘密情報をYAMLに書かず、ホスト環境変数から受け取り
  • ゲームエンジン対応（Godot / Unity / Unreal の実例）
ブラウザ ダッシュボード

非エンジニアも、ボタンひとつで。

sebastian-ci serve でローカルWeb画面を起動。設定をブラウザで編集して「保存して検証」、「実行する」で走らせると、 ログが WebSocket でリアルタイムに流れます。履歴の行をクリックすれば、 ジョブごとの結果とログをその場で閲覧できます。

重いジョブは、別のマシンへ。

ジョブに remote: true を付けると、最も空いているエージェントへ自動で割り当て。接続できなければ次のエージェントへ切り替えます。

  • 🔀 自動負荷分散：実行中ジョブ数が最少のエージェントを選択
  • 🛟 フェイルオーバー：接続不可なら次の空きエージェントへ
  • 🔐 トークン認証：--token でエージェントを保護
  • 📦 ソース同期：マスターのコミットを圧縮して転送
  • 🔻 差分転送：2回目以降は変更ファイルだけを送信
  • 📡 逐次ストリーミング：リモートの出力を1行ずつ手元へ
クイックスタート

3ステップで、最初のパイプライン。

必要なのは .NET 8 SDK・Git・Podman（または Docker）だけ。

1

ビルドする

shell
$ dotnet build src/SebastianCi \
    -c Release
2

定義ファイルを置く

.sebastian-ci.yaml
image: alpine:3.20
jobs:
  test:
    script: ["echo hello"]
3

実行する

shell
$ sebastian-ci /path/to/repo
✅ 成功 test  0.4s
+

GUIで使う / 分散する

shell
# ブラウザ画面
$ sebastian-ci serve . --port 8080
# エージェント
$ sebastian-ci agent . --token …
